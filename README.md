# THA-Cup-App-Research-v1.0

股関節透視写真の手動5点計測と幾何シミュレーター。index.html をブラウザで開いて使用します。

## 任意の追加計測（試作）

1. 「写真から角度計測」で画像を読み込み、既存の H1/H2/A/B/C の5点を指定します。
2. 「脚長差・校正の点を追加」を選択し、画像左・右の同じ基準の小転子点 LT_A/LT_B を指定します。
3. 必要に応じて既知長の両端 S1/S2 を指定し、実物の長さを入力します。32 mm は仮の初期値です。
4. 点はドラッグで修正できます。「追加点を消去」は既存5点を保持し、追加4点だけを消去します。

脚長差は H1–H2 への垂直距離の差（画像右B−画像左A）。正なら画像右の点が画像下方にあります。患者の左右とは自動対応しません。未校正時は内部画像座標のpx、校正後はmmです。読み込み時の内部画像は最大1800pxへ縮小されるため、表示pxは元ファイルのpxと異なる場合があります。

画像面内の基準線傾きは水平に対する H1–H2 の角度（画像右下がりが正）です。矢状面の骨盤前後傾とは異なります。

## 制限・プライバシー

追加機能は研究・操作検証用の未検証プロトタイプで、診断・治療・手術判断には使用しないでください。臨床精度と再現性は未検証です。撮影角度、回旋、姿勢、倍率、打点の影響を受けます。校正には画像対象と同じ深さの既知長を推奨します。カメラ写真の射影歪みは補正しません。

画像はブラウザ内で処理し、外部送信や自動保存を行いません。匿名化済み画像を使用してください。患者画像・秘密情報はこのリポジトリに含めないでください。
